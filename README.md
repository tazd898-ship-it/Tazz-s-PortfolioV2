# T.AZZ Portfolio

A responsive portfolio inspired by the supplied purple/cyber esports-style reference.

## Run it
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Edit it
- `index.html` — text, sections, projects and links
- `style.css` — colors, spacing, animations and layout
- `script.js` — interactions

Replace `hello@example.com`, social links and project descriptions with your own details.
